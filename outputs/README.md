# Outputs

`analysis_results/` contains source-derived table profiles, key checks, KPI summaries, monthly sales, category/state summaries, payment mix, review distribution and business insights. These CSVs are regenerated by `build_outputs.py`.

`charts/` is available for exported chart images. The Excel workbook contains two embedded charts, and the notebook displays monthly revenue, monthly order volume, category, state, review and delivery-time charts when run with its listed libraries.
